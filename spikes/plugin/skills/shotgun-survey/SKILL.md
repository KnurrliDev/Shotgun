This skill is a test of phase 0. Do these steps:

1. Call the MCP tool with the name that ends with `shotgun_get_session`. The DataFlow plugin supplies this tool.
2. Reply with 1 line: "Survey skill loaded, marker: " and the value of `marker` from the tool.
